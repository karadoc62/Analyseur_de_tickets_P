# Mini projet - Analyseur de tickets avec IA locale

## Auteur
Frédéric Gobfert

## Status
En cours de réalisation

## Objectif
L’objectif final est de recevoir un ticket contenant un message d'un utilisateur. Le backend Python envoie ce texte à un petit LLM local, par exemple Qwen via Ollama. Le modèle doit répondre en JSON avec une catégorie, une priorité et un résumé. Ensuite Python valide ce JSON et l’interface web affiche proprement le résultat.

## Remarques
Ce projet est un projet d'apprentissage Python.
